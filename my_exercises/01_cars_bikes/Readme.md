# 01 - Cars and Bikes

Practice exercise with product cards for a car and a bike, using a dark theme with yellow highlights.

## Colors

| Name | Hex | Usage |
|---|---|---|
| Yellow1 | `#febe01` | Price and button background |
| Yellow2 | `#332200` | Button text |
| Black | `#111` | Card background |
| Gray | `#b2b2b2` | Description text |
| White | `#fff` | Page background |
