# HTML & CSS Fundamentals

Welcome to my HTML & CSS repository! 👋

This repository contains the exercises and academic projects I developed while learning front-end web development fundamentals, as part of my Biomedical Informatics undergraduate program at the **Federal University of Health Sciences of Porto Alegre (UFCSPA)**.

As a Biomedical Scientist currently transitioning into Software Development, I created this repository to document my learning journey and demonstrate my progress in web development through practical exercises and projects.

---

## 📚 Topics Covered

Throughout this repository, I explore and practice the fundamental concepts of HTML and CSS, including:

- HTML Document Structure
- Semantic Elements
- Links & Navigation
- Multi-page Projects
- CSS Selectors (classes, elements)
- Text & Typography Styling
- Colors & Backgrounds
- Box Model
- Flexbox & Grid Layout
- Responsiveness (Media Queries)

---

## 🎯 Purpose

The purpose of this repository is to:

- Document my learning journey in front-end web development.
- Practice fundamental HTML and CSS concepts.
- Improve my ability to structure and style web pages.
- Build a programming portfolio throughout my Biomedical Informatics degree.
